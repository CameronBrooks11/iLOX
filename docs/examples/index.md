# Examples

Working examples from [`examples/`](https://github.com/CameronBrooks11/iLOX/tree/main/examples)
in the repository, each shown as an embedded 3D model:

- [Radial tessellation]({% link examples/radial.md %}) — interlocking cells on a
  hexagonal (rotationally symmetric) lattice.
- [Rectangular tessellation]({% link examples/rectangular.md %}) — interlocking
  cells on a rectangular grid with substrates.

Each page embeds a pre-rendered model — click **View 3D** for a rotatable view,
or **Customize (live)** to load the in-browser OpenSCAD customizer and edit the
parameters yourself. The customizer offers the numbers and choices; the division
line `div` and the `voids` are lists of points, which it does not offer, so
change those in the `.scad` file.
